# 📝 My To-Do List Application

This is a simple and interactive *To-Do List web application* developed using *HTML, CSS, and JavaScript*.  
It allows users to add tasks, mark them as completed, and delete tasks easily.

---

## 🎯 Project Objective

To build a basic front-end project that helps users manage daily tasks while practicing core web development concepts.

---

## 🚀 Features

- Add new tasks
- Mark tasks as completed using a checkbox
- Delete tasks using the delete button
- Clean and user-friendly interface

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript  

---

## 📂 Project Structure
My-To-Do-List/
index.html
style.css
script.js

## ▶️ How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open index.html in any web browser
4. Start adding your tasks

---

## ✅ Project Requirements Covered

✔ User can add tasks  
✔ User can delete tasks  
✔ User can mark tasks as completed  
✔ Simple and clear UI
